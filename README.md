# Jun Zhang's Portfolio Website (2017)

Welcome to the source code of **Jun Zhang's personal portfolio website**, originally created in **2017** and hosted via **GitHub Pages**.

## ✨ Background & Reflection

This website was hand-coded using **HTML**, **CSS**, and **JavaScript** at a time when **user experience design** had not yet been influenced by the recent rise of AI tools. Every line of code was written manually, and the process was extremely time-consuming and mentally demanding.

As a UX designer fresh out of school, having a **responsive personal website** to showcase my work was crucial for job hunting. This site became a vessel for my resume, project experiences, and design inspirations. It may not be perfect, but it represents a heartfelt effort — from struggling with CSS layouts to debugging unfamiliar style properties.

I believed in the philosophy of "**show more than say**", and this website was my way of expressing that.

## 📁 Project Structure

The website includes:

- `docs/` — Contains the deployed website files for GitHub Pages
  - `index.html` — Homepage
  - Additional HTML pages
  - `css/`, `js/`, `images/`, `pdf/` — Supporting assets

## 🚀 Deployment

This site is deployed using **GitHub Pages**, with the `docs/` folder configured as the publishing source.
